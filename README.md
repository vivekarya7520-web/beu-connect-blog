# BEU Connect Blog

Official blog content repository for [BEU Connect](https://www.beuconnect.in/).

## About

This repository stores blog articles, thumbnails, author images and category information used by the BEU Connect Blog.

## Repository Structure

- `blog/articles/` – Blog articles in Markdown.
- `blog/images/` – Article thumbnails and author images.
- `blog/categories.json` – Blog categories.
- `blog/ARTICLE_TEMPLATE.md` – Article writing template.
