# BEU Connect Blog Articles

This directory contains all blog articles published on BEU Connect.

## Article Creation

1. Copy the ARTICLE_TEMPLATE.md file.
2. Create a new Markdown file in this directory.
3. Use a descriptive filename based on the article slug.
4. Fill in all frontmatter metadata.
5. Write the complete article in Markdown.
6. Set status to `draft` while preparing.
7. Change status to `published` when ready.

## Guidelines

- Every article must have a unique slug.
- Use the correct category slug from categories.json.
- Add a relevant thumbnail from blog/images/.
- Use the author profile image path provided in the template.
- Write original, accurate and useful content.
- Verify spelling, links and formatting before publishing.
